# Testing

Run `pnpm test` for deterministic domain, auth, persistence mock, and local API tests. The API test starts Express with Google Cloud integrations disabled and checks health, validation, demo-mode writes, and deterministic plan/copilot fallback. Auth tests cover bearer parsing, verified identity, invalid/missing tokens, and ownership comparison. A fake Firestore repository covers create, cross-user read/update/list/delete denial, and persistence failures. Domain tests cover allocation reconciliation and overspending, task cycles/missing dependencies/blocked prerequisites/date changes, and CSV quoting/formula protection. Run `pnpm check` for JavaScript syntax checks, `pnpm build` for the production frontend, and `pnpm audit --prod` for the production dependency audit.

The browser walkthrough was performed against Vite local demo mode: sample event loaded; category added; guest added; vendor and task forms reviewed; blocked task completion refused; local plan generated with an explicit no-Gemini label. It was a manual UI check, not automated E2E and not a formal accessibility audit. No Firebase token, Firestore emulator, Vertex model, or paid/live service call was used. Remaining checks: real Firebase sign-in and ID-token route calls; Firestore Emulator CRUD/ownership/failure integration; Vertex structured-output and quota behavior with safe test credentials; Cloud Run image/startup and live probe; keyboard-only and screen-reader testing; responsive and contrast audit at supported viewports; independent CSV spreadsheet import check.
